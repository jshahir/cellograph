# Cellograph

Cellograph is a graph neural network model that uses a two-layer graph convolutional network to analyze single-cell RNA sequencing data (but can extended to other single-cell modalities). You can read more about it in our publication in BMC Bioinformatics: [Shahir et al, 2024](https://link.springer.com/article/10.1186/s12859-024-05641-9).

You can install using `pip install cellograph`

To learn how to implement Cellograph, take a look at our tutorial [here](https://github.com/jshahir/cellograph/blob/main/CellographHumanOrganoid.ipynb).
